Dashboard de Vendas — TOTVS

Meta vs. realizado, pipeline e detalhamento por cliente/produto. Os dados ficam só neste navegador.

📥 Importar lançamentos (colar da planilha ou enviar CSV)

Cole as linhas copiadas direto da sua planilha (Ctrl+C num intervalo de células) na caixa abaixo, ou envie um arquivo .csv. Ordem esperada das colunas: Data, Cliente, Produto, [Status], Valor CDU, Valor Recorrente, Valor Serviços, Valor Total, Vendedor — a coluna Status é opcional (se ausente, o lançamento é tratado como Ganha).

Aceita separador por tabulação (padrão ao colar do Excel), ponto-e-vírgula ou vírgula. Números no formato brasileiro (1.234,56) e datas dd/mm/aaaa são reconhecidos automaticamente.
Cada lançamento é comparado por data + cliente + produto + total; linhas idênticas às já importadas são ignoradas automaticamente, então é seguro colar o mesmo intervalo mais de uma vez.
✏️ Adicionar um lançamento manualmente
Valor Total é calculado automaticamente (CDU + Recorrente + Serviços).
